# Ars Tech — Brand Design System

Version: 1.0
Brand: Ars Tech
Handle: @arstechid
Tagline: Built to Innovate.

---

## 1. Brand Direction

Ars Tech is a technology brand focused on building practical digital
solutions for businesses.

The visual identity should communicate:

- Modern
- Professional
- Technology-driven
- Clean
- Reliable
- Innovative
- Approachable

The brand should feel like a modern technology company, not a generic
IT service or corporate consulting company.

### Visual Keywords

Clean / Modern / Digital / Structured / Minimal / Technical / Blue

### Core Principle

> Simple structure. Strong typography. Clear message. Purposeful visuals.

Every design should prioritize clarity before decoration.

# 3. Logo System

## Primary Logo

Use the official Ars Tech logo without modification.

The logo should never be:

- Stretched
- Rotated
- Recolored arbitrarily
- Distorted
- Given unnecessary effects
- Placed over visually noisy backgrounds

## Logo Variants

Preferred variants:

1. Full logo — icon + Ars Tech
2. Symbol — Ars Tech icon only
3. White/reversed version for dark backgrounds

## Clear Space

Always maintain clear space around the logo.

Minimum clear space:

`1× logo symbol height`

No text, illustration, border, or other graphic element should enter
this area.

## Minimum Size

The logo must remain clearly recognizable.

For small applications, prefer the symbol instead of forcing the full
logo into limited space.

# 4. Color System

The Ars Tech identity is built around blue, deep navy, white, and
neutral tones.

## Primary Colors

### Ars Blue

`#087CFF`

Usage:

- Primary accent
- Important words
- CTA
- Icons
- Highlights
- Data visualization emphasis

### Deep Navy

`#071A3D`

Usage:

- Dark backgrounds
- Headlines
- High-contrast sections
- Premium/technical layouts

### White

`#FFFFFF`

Usage:

- Main light background
- Text on dark surfaces
- Cards
- Negative space

---

## Supporting Colors

### Soft Background

`#F5F8FC`

Used for subtle separation on light layouts.

### Secondary Text

`#667085`

Used for:

- Supporting copy
- Descriptions
- Metadata

### Border

`#E5EAF0`

Used for:

- Card borders
- Dividers
- Subtle structural elements

---

# 5. Gradient

Gradients are supporting elements, not the primary identity.

Preferred direction:

Deep Blue → Ars Blue → Light Blue

Example:

`#071A3D → #087CFF → #31B7FF`

Use gradients for:

- Hero graphics
- Glow
- Abstract technology visuals
- Small highlights
- Background depth

Avoid excessive rainbow or multicolor gradients.

Blue should remain dominant.

---

# 6. Typography

## Primary Typeface

**Inter**

Fallback:

`Inter, Helvetica, Arial, sans-serif`

Use one primary font family whenever possible.

---

## Typography Hierarchy

### Display

Weight: 700–800

Used for:

- Hero messages
- Campaign headlines
- Large statements

### Heading

Weight: 700

Used for:

- Section titles
- Post titles
- Presentation headings

### Subheading

Weight: 500–600

Used for:

- Supporting statements
- Category labels

### Body

Weight: 400–500

Used for:

- Descriptions
- Paragraphs
- Supporting information

### Caption

Weight: 400–500

Used for:

- Metadata
- Footer
- Small labels

---

## Typography Rules

Prefer short headlines.

Good:

> We Build Digital Systems  
> That Move Businesses Forward.

Avoid unnecessarily long headlines.

Use bold typography to establish hierarchy.

Highlight only important words using Ars Blue.

Do not use multiple decorative fonts.

Maximum recommended font families per design:

**1**

---

# 7. Spacing System

Use an 8-point spacing system.

Base unit:

`8px`

Recommended values:

`8 / 16 / 24 / 32 / 48 / 64 / 80 / 96`

Spacing should feel intentional and consistent.

Avoid arbitrary spacing such as:

`13px / 27px / 43px`

unless technically necessary.

---

# 8. Grid & Alignment

Prefer structured layouts.

Primary alignment:

**Left aligned**

Centered layouts are allowed when the composition requires them.

Avoid mixing multiple alignment styles without reason.

## General Layout

Recommended structure:

[ Brand / Context ]

[ Main Message ]

[ Supporting Content ]

[ Visual / Information ]

[ Footer / CTA ]

Not every design must contain all sections.

---

# 9. Corner Radius

Ars Tech uses soft geometric shapes.

Recommended:

Small:
`8px`

Medium:
`12px`

Large:
`16–20px`

Cards should feel modern but not excessively rounded.

Avoid pill-shaped containers unless they are:

- Tags
- Buttons
- Small labels

---

# 10. Borders & Shadows

## Borders

Preferred:

`1px solid #E5EAF0`

Borders should be subtle.

## Shadows

Use soft shadows only when necessary to establish depth.

Avoid:

- Heavy drop shadows
- Black dramatic shadows
- Strong glow around every object

Depth should feel subtle and modern.

---

# 11. Iconography

Preferred icon style:

- Simple
- Geometric
- Consistent stroke
- Modern
- Minimal detail

Use one icon family/style within the same asset.

Preferred presentation:

Blue icon + neutral background

or

White icon + blue/dark background

Avoid mixing:

- 3D icons
- Filled cartoon icons
- Outline icons
- Emoji

within the same visual system.

---

# 12. Illustration & Visual Language

Visuals should reinforce technology and business systems.

Preferred themes:

- Software interfaces
- Dashboards
- Automation
- Connected systems
- Data
- Code
- Digital workflows
- Devices
- Abstract technology

Preferred visual treatment:

- Minimal 3D
- Isometric technology illustration
- Clean UI mockups
- Abstract geometric forms
- Subtle blue glow
- Grid patterns
- Dot patterns
- Thin connecting lines

Visuals must support the message.

Never add illustrations only to fill empty space.

---

# 13. Graphic Elements

Approved supporting elements:

- Dot grids
- Thin lines
- Small geometric shapes
- Subtle circles
- Grid patterns
- Blue glow
- Abstract waves
- Technical diagrams

These elements should remain secondary.

Recommended opacity:

`5–20%`

They should add depth without competing with the content.

---

# 14. Photography

When photography is used, prefer:

- Technology
- Business environments
- Devices
- Teams working naturally
- Real products
- Real business environments

Avoid generic corporate stock imagery such as:

- Fake handshakes
- People pointing at invisible charts
- Overly staged office scenes

Photography may use subtle blue treatment when appropriate.

Text:
Deep Navy

Accent:
Ars Blue

- Educational content
- Documents
- Process explanation
- Information-heavy layouts

## Dark

Background:
Deep Navy

Text:
White

Accent:
Ars Blue / Light Blue

Best for:

- Hero content
- Product showcase

---

# 16. Composition

Every visual should have one dominant focal point.

Priority:

1. Main message
2. Supporting information
3. Visual
4. Brand identification

Do not allow all elements to compete equally.

Use negative space intentionally.

Empty space is part of the design.

---

# 17. Content Density

Avoid overcrowding.

If information becomes difficult to scan:

- Reduce copy
- Break information into sections
- Use multiple pages/slides
- Move details into captions or supporting content

Do not solve content density by simply reducing font size.

---

# 18. Brand Applications

This system should remain recognizable across:

### Social Media

Use strong headline hierarchy and recognizable branding.

### Website

Prioritize usability, spacing, readability, and clear CTA.

### Presentation

Use simple layouts with one main idea per slide.

### Business Card

Keep information minimal and typography clean.

### Proposal / Document

Use white backgrounds, clear hierarchy, and restrained brand accents.

### Poster / Marketing Material

Allow larger typography and stronger visual expression while
maintaining the core identity.

### Product / Packaging

Prioritize logo recognition and simple communication.

---

# 19. Social Media Extension

Recommended social canvas:

`1080 × 1350 px`

Ratio:

`4:5`

Recommended safe margin:

`64–80px`

Possible layout families:

### Hero

Large statement + supporting visual.

### Educational

Headline + structured information/cards.

### Product / Service

Product/service as primary focal point.

### Case Study

Problem → Solution → Result.

### Process

Sequential steps or workflow.

Layouts may change.

Brand rules should not.

# 21. CTA Style

CTA copy should be short and direct.

Examples:

- Learn More
- Explore Our Solutions
- Let's Build
- Contact Us
- Start Your Project

Primary CTA:

Ars Blue background + white text

Secondary CTA:

Transparent/light background + Deep Navy text

Avoid multiple competing primary CTAs.

---

# 22. Design Do

DO:

- Use strong hierarchy
- Keep layouts clean
- Maintain generous whitespace
- Use blue intentionally
- Keep typography consistent
- Use consistent icons
- Maintain grid alignment
- Make the message understandable quickly
- Keep decorative elements subtle

---

# 23. Design Don't

DON'T:

- Introduce random brand colors
- Use excessive gradients
- Use excessive glow
- Mix multiple illustration styles
- Use random fonts
- Overload layouts
- Stretch the logo
- Fill every empty area
- Use decorative elements without purpose
- Make every element blue
- Change visual direction for every new asset

---

# 24. AI Design Instructions

When generating visual assets using AI, always preserve the Ars Tech
brand identity.

Use this baseline instruction:

"Create a modern, clean technology brand visual for Ars Tech.
Use a structured minimal layout, strong typography, generous whitespace,
deep navy and white as primary surfaces, Ars Tech blue (#087CFF) as the
main accent, subtle technology-inspired graphic elements, and a
professional digital-product aesthetic.

Avoid generic corporate templates, excessive gradients, random colors,
cartoon styling, excessive visual effects, and overcrowded layouts.

The final result should feel consistent with a modern software and
technology company."

Additional instructions should define:

- Asset dimensions
- Content
- Purpose
- Light or dark mode
- Required logo
- CTA
- Supporting visual

Never let individual prompts override the core brand system unless
explicitly requested.

---

# 25. Brand Consistency Test

Before approving an asset, check:

1. Does it look like Ars Tech without reading the username?
2. Is blue being used consistently?
3. Is typography consistent?
4. Is there one obvious focal point?
5. Is spacing structured?
6. Are visual elements supporting the message?
7. Is the logo used correctly?
8. Does the asset feel modern and technology-focused?
9. Is unnecessary decoration removed?
10. Would this asset still fit beside other Ars Tech materials?

If several answers are "no", revise the design before publishing.

---

# 26. Core Rule

The Ars Tech brand does not require every asset to look identical.

It requires every asset to feel like it came from the same system.

Consistency comes from:

**Color + Typography + Spacing + Grid + Visual Language + Brand Voice**

—not from repeating the exact same template.
